# Student Data Management System

## Description

Student Data Management System is a C program that manages student records using a Singly Linked List data structure.

The project allows users to add, display, modify, delete, sort, reverse, and save student records.

## Features

- Add a new student record
- Display all student records
- Delete a student record
- Modify student details
- Search students by roll number, name, or percentage
- Sort records by name or percentage
- Delete all records
- Reverse the linked list
- Save student records to a file

## Technologies Used

- C Programming
- Structures
- Pointers
- Singly Linked List
- Dynamic Memory Allocation
- File Handling

## Project Files

| File | Description |
|------|-------------|
| `main.c` | Main menu and program execution |
| `student.c` | Student data management functions |
| `student.h` | Structure and function declarations |
| `student defination.c` | Additional student-related functions |
| `student.dat` | Student data file generated by the program |
